# 🎮 Gamepad Tester Pro - by xCapitann

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

Una herramienta web profesional, rápida y precisa para probar el estado de tus mandos de consola (PlayStation, Xbox y Genéricos). Ideal para técnicos, modders y gamers que necesitan diagnosticar **stick drift** o fallos en los botones.

## ✨ Características

- **Detección Automática:** Identifica si tu mando es de PlayStation o Xbox y cambia el diseño visual.
- **Prueba de Sticks (L3/R3):** Visualización en tiempo real con alta precisión para detectar "drift".
- **Testeo de Botones:** Panel dinámico que ilumina cada botón presionado (incluyendo valores analógicos de gatillos).
- **Rendimiento Optimizado:** Ejecución a 60 FPS con `requestAnimationFrame` para una respuesta instantánea.
- **Efectos Visuales:** Retroalimentación con brillo (Glow) según la marca del mando conectado.
